# 雙老健檢優先指數

這份研究回應黑客松第六題，整合屋齡、結構、高齡人口、液化與救援條件。42,141 棟歷史使照代表的建物算出雙老健檢優先指數（Twin-Ageing Inspection Priority Index，TAIPI），前 1% 為 423 棟候選；選案效益尚未驗證。公辦都更還要接上基地、意願與財務，這份研究只做第一環的建物風險。

這份研究以[市政 debug松](https://puma.taipei/hackathon)第六題「危老耐震如何查，風險評級怎麼找」為起點；我們從活動的七個題目中選了這一題。活動由沈伯洋競選辦公室主辦；本專案獨立進行，與主辦單位沒有合作關係，也不是市府委託。

## 從這裡開始

1. **[展示頁：雙老健檢優先指數](https://flsteven87.github.io/puma-hackathon/demo/issue-6-building-rating.html)** 給一般讀者，從居民困難讀到分析結果與後續查核。
2. **[研究報告](https://flsteven87.github.io/puma-hackathon/topics/issue-6-building-resilience.html)** 現行做法、方法、各項檢查與限制。
3. **研究文件（英文）：** [完整證據與來源](docs/topics/issue-6-building-resilience.md)、[單棟計算方法](docs/topics/issue-6-building-rating.md)。

## 展示頁怎麼讀

- **第一屏：** 原題的「人老＋屋老」與居民反映，接著是三個數字與建議的邀請方式。
- **查你家附近的里：** 選行政區和里，看這個里有幾棟在前 1%、幾棟在其餘前 10%；只到里，不公開個別建物。
- **這份研究做哪一環：** 老屋健檢直接排出先查哪一棟；公辦都更先做建物風險這一環。
- **雙老健檢優先指數：** 結構估值為底，周邊長者、救援困難與液化各往上加成，沒有一項會讓分數歸零。
- **用一筆老屋紀錄串起計算：** 看不同尺度的資料如何接合、形成分數，再回到全體分布理解前 1% 候選；入選不代表方法已驗證有效。
- **邀請前各要補哪一步：** 前 1% 候選依管理組織與書面現況分組，邀請仍照指數先後；最後是只有現場看得到的事。
- **延伸討論：** 日本與其他地方怎麼排先後、臺灣震損資料、換了假設的結果與地理分布。

## 結果

- 前 1% 候選 423 棟（分數最高的 1%），來自 375 張歷史使照，分布在 102 個里，全是 8 到 18 層的大樓；其餘前 10% 3,824 棟。結構估值用每筆使照記載的建物高度。
- 名單幾乎取決於「同年代大樓的結構估值約是中樓層兩倍」這一點，它還沒有臺灣震災資料驗證：大樓改用中樓層的估值，原本 423 棟只剩 30 棟留在前 1%。
- 取消中樓層加重，仍有 396 棟留在前 1%；查不到液化資料的位置全改成最高加成，仍有 410 棟留下。
- 對照市府 2025 年地形圖做書面初查：269 棟相符，154 棟樓層不同、門牌對不到或圖資需另查，要先到現場確認。書面相符不等於確認是原建物。
- 有管委會報備、書面現況也相符的 174 棟，可以直接發出主動初評邀請；其餘依情況先確認現況、輔導成立組織或確認評估途徑。

還沒驗證的是：每一棟是否仍是原建物、實際耐震能力如何，以及照這份名單選案是否比現行做法更好。分數低不代表安全，也不能據此不去評估。

## 真實資料與模擬資料

計算用的資料都是真實的公開紀錄，沒有使用模擬資料：

- 臺北市歷史使用執照（公開整理版）：屋齡、樓層、構造
- 臺北市政府消防局搶救不易狹小巷道清冊、消防通道清冊
- 臺北市土壤液化潛勢圖
- 內政部最小統計區人口年齡資料
- 臺北市建築管理工程處公寓大廈管理組織報備資料、可輔導成立清冊
- 臺北市更新地區範圍圖、市府 2025 年 3D 建物圖層
- 國家地震工程研究中心的評估手冊與震損調查資料

受損估值採評估手冊的設計地震情境；周邊長者比例（依排名）、巷弄與液化三項加成，以及採前 1%、10% 作展示範圍，都是研究選擇。加成各試 0%、25%、50%，沒有經驗校準；三項各加 25% 會共同乘上約 1.95 倍，這個交互效果來自公式。10,800 組計算變動工程解讀、年代與政策加成；入選頻率不能單獨視為工程信心或效益驗證。受損機會依國震中心的評估手冊估算，由我們自行重建，不是國震中心的官方結果。部分資料公開可讀，但不一定有開放授權，詳見研究文件。完整來源、取得日期與限制，見[研究文件](docs/topics/issue-6-building-resilience.md)。

## 如果市府上任 100 天內要落地

以下是待與機關討論的驗證構想，還沒有確認資源與程序。應先檢驗三項加成的幅度與因素間的交換關係，再決定是否採用或修訂排序。

| 時間 | 做什麼 | 誰來做 |
| --- | --- | --- |
| 第 1 個月 | 釐清因素取捨、加成幅度與比較基準；同步核對候選建物現況及既有評估紀錄 | 建築管理工程處 |
| 第 2 個月 | 依核對需求與可用人力安排現場查核，包含 154 棟書面需核對者；確認各類建物可走的評估程序 | 建築管理工程處，搭配專業評估人員 |
| 第 3 個月 | 依可取得的評估結果，比較事先約定的選案規則；證據不足時保留結論，不預設擴大試辦 | 建築管理工程處；更新地區另請都市發展局評估 |

**需要的資料：** 建物現況、既有耐震評估紀錄、管理組織報備，以及主動初評的邀請與結果。

**成本：** 本研究沒有可信的估算。主要是承辦人力與專業評估費用；評估補助依現行規定辦理。

## 這份研究的界線

- 使照紀錄不等於現存建築：早年磚造的定位率較低，沒出現在名單上的房子，不能因此當成需求低。
- 液化圖描述區域潛勢，不能診斷地基；長者比例是所在最小統計區的統計，不是每棟住戶的年齡。
- 1% 和 10% 是政策選擇，不是安全門檻；巷弄和液化要加多少，也是政策選擇。
- 公開版只放彙總結果與方法，不含個別建築名單、原始資料與計算程式。
