# 哪些老房子，該先做耐震健檢？

我們用歷史使照連結液化、狹小巷弄和長者比例等公開資料，替臺北 38,345 棟老屋算出優先分數，列出建議優先調查的 385 棟，並說明市府下一步怎麼核對。

這份研究以[市政 debug松](https://puma.taipei/hackathon)第六題「危老耐震如何查，風險評級怎麼找」為起點；我們從活動的七個題目中選了這一題。活動由沈伯洋競選辦公室主辦；本專案獨立進行，與主辦單位沒有合作關係，也不是市府委託。

## 從這裡開始

1. **[展示頁：哪些老房子，該先做耐震健檢？](https://flsteven87.github.io/puma-hackathon/demo/issue-6-building-rating.html)** 給一般讀者，幾分鐘讀完。
2. **[研究報告](https://flsteven87.github.io/puma-hackathon/topics/issue-6-building-resilience.html)** 現行做法、方法、各項檢查與限制。
3. **研究文件（英文）：** [完整證據與來源](docs/topics/issue-6-building-resilience.md)、[單棟計算方法](docs/topics/issue-6-building-rating.md)。

## 展示頁怎麼操作

- **拿一棟老屋，帶你算一遍：** 從第一優先挑一棟當例子，三步算出它的分數。
- **換一條線看看：** 拖動滑桿，從前 0.5% 拉到前 10%，看名單和分布的里數怎麼變。
- **在哪些里、走哪條路：** 第一優先的地圖、各里棟數，以及每一類房子接下來可以走的程序。

## 結果

- 第一優先 385 棟（分數最高的 1%），來自 221 張歷史使照，分布在 62 個里；第二波（前 1% 到 10%）3,467 棟。
- 取消還沒用臺灣資料驗證的中樓層加重，仍有 332 棟留在第一優先。
- 查不到液化資料的位置全改成最高加成，仍有 384 棟留在第一優先。
- 對照市府 2025 年地形圖，311 棟的位置與樓層和使照相符；其餘 74 棟要先到現場確認。

還沒驗證的是：每一棟是否仍是原建物、實際耐震能力如何，以及照這份名單選案是否比現行做法更好。分數只用來排調查的先後，不是安全判定。

## 如果市府上任 100 天內要落地

以下是依研究結果提出的構想，還沒有和任何機關確認。

| 時間 | 做什麼 | 誰來做 |
| --- | --- | --- |
| 第 1 個月 | 書面核對 385 棟的現況、既有評估紀錄與管理組織，先處理 311 棟與使照相符的部分 | 建築管理工程處 |
| 第 2 個月 | 74 棟到現場確認；四、五層公寓向屋主說明危老結構評估補助；6–7 層有管委會的，核對主動初評條件 | 建築管理工程處，搭配專業評估人員 |
| 第 3 個月 | 把主動初評的實際邀請與結果和這份名單對照，決定要不要調整巷弄、液化的加成 | 建築管理工程處；更新地區另請都市發展局評估 |

**需要的資料：** 建物現況、既有耐震評估紀錄、管理組織報備，以及主動初評的邀請與結果。

**成本：** 本研究沒有可信的估算。主要是承辦人力與專業評估費用；評估補助依現行規定辦理。

## 這份研究的界線

- 使照紀錄不等於現存建築：早年磚造的定位率較低，沒出現在名單上的房子，不能因此當成需求低。
- 液化圖描述區域潛勢，不能診斷地基；長者比例是所在最小統計區的統計，不是每棟住戶的年齡。
- 1% 和 10% 是政策選擇，不是安全門檻；巷弄和液化要加多少，也是政策選擇。
- 公開版只放彙總結果與方法，不含個別建築名單、原始資料與計算程式。
